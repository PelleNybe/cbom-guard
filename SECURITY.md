# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.1.x` | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability in `cbom-guard`, please report it responsibly to **Corax CoLAB** at `security@coraxcolab.com` rather than opening a public GitHub issue. We will acknowledge receipt within 48 hours and coordinate a fix and advisory.
